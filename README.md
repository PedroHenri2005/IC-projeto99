# IC-projeto99

Resumo:

Este projeto investiga a aplicação de técnicas avançadas de inteligência artificial, com foco em modelos multimodais de visão e linguagem (VLMs), visando o aprimoramento da experiência do usuário na plataforma de entrega de alimentos da 99/DiDi. 
O plano de pesquisa inicia-se com o embasamento teórico e o levantamento de literatura científica pertinente sobre aprendizado multimodal e visão computacional. 
Futuramente, busca-se explorar o desenvolvimento de um modelo VLM interativo, capaz de auxiliar o usuário durante a navegação no aplicativo, mitigando gargalos operacionais e promovendo soluções inovadoras para a plataforma.
